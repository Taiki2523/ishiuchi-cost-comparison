# Feature Specification: 1月の料金を選ぶ見積もり

**Status**: Draft

## User story

幹事として、アーバンヒル石打の2027年1月の出発日を一つ選び、掲載料金で5人分の旅費を見積もりたい。

## Requirements

- 大人5名・1泊2日・夕朝食付きの公式掲載額を重複なしで昇順表示する。選択した料金の該当日、出典、確認日を表示する。
- 一つの出発日に対し、参加者別、5人合計、支払先別の見積もりを再計算する。2案の比較は不要。
- 2日券は全員分を計上する。追加料金は1人5,400円とする。
- 選択した料金をJSONと下書きに保存する。v1〜v4は従来の低いほうの基本料金11,000円を既定値として復元する。
- 選択肢にない料金のJSONを拒否し、既存入力は維持する。保存・共有の匿名既定値を維持する。

## Acceptance

- 全員東京発、基本レンタル、追加オプションなしの場合、11,000円選択時は164,000円、19,200円選択時は205,000円。
- 料金を切り替えると明細と共有文も更新され、保存して開き直すと選択が復元される。
- 掲載額は確認時点の参考情報として表示し、最新の予約可否は公式カレンダーで確認できる。

## 変更要件 · 料金選択を出発日カレンダーに変更

- 2027年1月の月間カレンダーに1人あたりの掲載料金を表示し、出発日を一つ選べる。確認時点で選択対象に入っていない日は選択不可。
- 選んだ出発日から料金を算出し、共有文に1泊2日の日程を載せる。1月31日出発の翌日は2月1日と表示する。
- JSON v6と下書きで出発日を保持する。旧JSON v5の料金は、同額の最初の掲載日に移行する。v1〜v4の既定料金は1月5日出発に相当する。
