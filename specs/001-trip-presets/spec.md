# Feature Specification: 1月の料金を選ぶ見積もり

**Status**: Draft

## User story

日程未定の幹事として、アーバンヒル石打の2027年1月の基本ツアー代を一つ選び、5人分の旅費を見積もりたい。

## Requirements

- 大人5名・1泊2日・夕朝食付きの公式掲載額を重複なしで昇順表示する。選択した料金の該当日、出典、確認日を表示する。
- 一つの選択に対し、参加者別、5人合計、支払先別の見積もりを再計算する。日程の決定や2案の比較は不要。
- 2日券は全員分を計上する。日程別の追加料金が未確定の間は1人4,100〜5,400円の概算とする。
- 選択した料金をJSONと下書きに保存する。v1〜v4は従来の低いほうの基本料金11,000円を既定値として復元する。
- 選択肢にない料金のJSONを拒否し、既存入力は維持する。保存・共有の匿名既定値を維持する。

## Acceptance

- 全員東京発、基本レンタル、追加オプションなしの場合、11,000円選択時は157,500〜164,000円、19,200円選択時は198,500〜205,000円。
- 料金を切り替えると明細と共有文も更新され、保存して開き直すと選択が復元される。
- 掲載額は確認時点の参考情報として表示し、最新の予約可否は公式カレンダーで確認できる。
